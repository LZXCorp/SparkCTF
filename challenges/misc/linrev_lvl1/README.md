# linrev_lvl1

"Just throw it in Ghidra, they said. It'll be easy, they said." - Anonymous Reverser, 2025

Welcome to the world of Linux binary reverse engineering! A mysterious developer has left behind a simple binary that seems to be hiding something. Your mission is to figure out what it wants and extract the secret flag hidden within.

Fire up your favorite disassembler and start digging. The binary is waiting, and it has something to tell you... if you know the right words to say.

Note: This binary was compiled for Linux x86_64. You'll need a Linux environment or a compatible VM to run it. Tools like Ghidra, IDA, or radare2 are your friends here.
