# winrev_lvl1

"Just throw it in IDA, they said. It'll be easy, they said." - Anonymous Reverser, 2025

Welcome to the world of Windows binary reverse engineering! A mysterious developer has left behind a simple executable that seems to be hiding something. Your mission is to figure out what it wants and extract the secret flag hidden within.

Fire up your favorite disassembler and start digging. The binary is waiting, and it has something to tell you... if you know what it's looking for.

Note: This binary was compiled for Windows x86_64. You'll need a Windows environment or a compatible VM to run it. Tools like Ghidra, IDA, x64dbg, or Binary Ninja are your friends here.
