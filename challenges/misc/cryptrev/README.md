# cryptrev

"Security through obscurity is my specialty!" - Anonymous Developer, 2025

We intercepted communications from a mysterious developer who seems to think that wrapping simple encryption in layers of obfuscation is the peak of security engineering. They've been using this setup to protect their most precious secrets. Your mission, should you choose to accept it, is to unravel their "unbreakable" system.

Peel back the layers of this cryptographic onion (tears optional, but likely). The flag is waiting inside flag_encrypted.txt, but first you'll need to understand what that overly-paranoid script is actually doing.

Note: To run the cryptrev.py script, ensure that you have Pyarmor installed (use pip or pip3 to install it by running: ``pip install pyarmor``)
