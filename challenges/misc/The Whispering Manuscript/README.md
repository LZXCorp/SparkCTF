# The Whispering Manuscript
A whimsical literary puzzle: find the hidden key in the manuscript and use it to decrypt the encrypted treasure.

## Summary
- **Author:** Aldric Liew
- **Category:** Misc
- **Learning Objective:** Practice locating hidden information in plain text, pattern recognition, and symmetric-key decryption.

## Files
- [`manuscript.txt`](./dist/manuscript.txt)
- [`treasure.enc`](./dist/treasure.enc)

## Hints
- `The secret is hidden in the text as a single word placed directly before a question mark.` (200 points)
