# PROTOCOL SP4RK - 1

Investigators have found SP4RK's secret hideout, hiding sensitive information relating to plans of world domination!

However, the hideout seems weirdly inaccessible. Further leads reveal that SP4RK created a Chromium browser clone with a slight modification to the HTTP requests, allowing them to access the hideout as if it were a normal website.

Your objective is to find a way to access the hideout.
