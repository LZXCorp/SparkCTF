# Misplaced File Tragedy
Oh no! Your colleague has forgotten where he placed all his scripts, which are stored in a text file. Luckily, he has saved a copy of his MFT table (for some reason) that may help him retrieve the full file path! Unfortunately, he doesn’t know how to work with MFT and will need your help to find the full path of the text file. The text file is called "spark" but there might be different files that may contain the same name. Are you up for the task and able to solve his problem? The full path should look something like "Program Files\7-Zip\7z.exe".
