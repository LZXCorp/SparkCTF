# ForenSeek
During a recent forensic investigation, analysts uncovered an encrypted ZIP file lurking on a compromised system. At first glance, the file seemed completely secure, but subtle traces suggested that the password might not be stored in any obvious location. Instead, fragments of critical information appear to linger in the less-traveled corners of the disk, hidden away where few would think to look. As a digital investigator, it’s your job to uncover this hidden piece of data, use it to unlock the archive, and retrieve the flag concealed within.
