# Digital Footprints
**SpArK.txt** has been tampered with... but the system keeps quiet records without anyone knowing. Can you find out how many times was the data overwritten, and when did the third overwrite happen? 

The flag format for this challenge is `SPARK{<number_of_overwrites>_<DDMMYY_of_third_overwrite><HHMMSS_of_third_overwrite>}`. For example, `SPARK{3_121225_115959}` means the file was overwritten 3 time, and the second overwrite happened on 12/12/2025 at 11:59:59.
