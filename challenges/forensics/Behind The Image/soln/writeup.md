## INTENDED SOLVING STEPS

1. You can put PDF files in free Online Editing tools (Ensure that they allow for image editing).
2. Move or delete the TETO image.
3. The image found behind the TETO image would be an Encrytped text: U1BBUkt7cGRmc19jYW5fYmVfcGFyc2VkfQ==
4. Decrypt using BAse64 which gives the flag.  

Note: pdf2text is another way to reveal file's content, but the Flag is on an image. 
      Changing the file to an SVG file to remove the image, will also work.
